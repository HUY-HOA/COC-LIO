# COC LIO

Ứng dụng Android tra cứu hồ sơ người chơi Clash of Clans bằng Player Tag.

## Hiện có
- Nhập Supercell Developer API Key.
- Nhập Player Tag.
- Tra cứu hồ sơ qua Clash of Clans API.
- Hiển thị cấp nhà chính, cấp kinh nghiệm, cúp, clan và thành tích.
- Lưu API key cục bộ trên thiết bị.

## Yêu cầu
Cần Supercell Developer API Key được cấp trong Supercell Developer Portal. IP thiết bị gọi API phải nằm trong danh sách IP được cho phép. API token xác minh trong game không thay thế Developer API Key.

## Build
GitHub Actions có workflow Build Android APK. Chạy thủ công trong tab Actions hoặc tự chạy sau mỗi lần push lên main.
